问题 1 · Clear selection

现状改法
一个满宽按钮横在列表和详情之间，把两块内容切开，视觉权重远高于它的使用频率删掉。取消选中有三条更自然的路径：详情头右侧的 ✕、Esc、再次点击已选中的行。空选中态时详情区整体塌陷，只留一条 9px 的拖拽条，列表自动吃掉这块高度。

问题 2 · 拥挤与截断

逐条对应截图里的具体位置
截图里的问题改法
生命体征行被裁掉：… Age · 47d Fres 断在窗口边缘，而且 Rollout ● NewReplicaSetAvailable Ready · 1/1 Up-to-date · 1 Available · 1 Strategy · RollingUpdate 全用同一个 · 分隔，读不出哪个是 label 哪个是 value拆成独立的 chip，每个 chip 内部是「小号灰标签 + 值」，边界靠边框而不是标点。整行 不换行不裁切，宽度不够时末尾收进 ⋯ 展开。NewReplicaSetAvailable 这种 reason 属于细节，移到 chip 的 tooltip 里，chip 只显示 ● Complete。
右栏值被裁掉：ghcr.io/containers/kubernetes-m，正好把 tag 裁没了——而 tag 是这一行唯一会变的信息长值一律 中间省略，永不裁尾：ghcr.io/containers/…/kubernetes-mcp:v0.3.1，tag 加粗。超长值（image、selector、annotation）改成两行式 KV：标签单独一行，值占满整栏宽度，附 ⧉ 复制和完整值 tooltip。
左栏空着，右栏挤爆：左边 45% 只放了 1 个 Pod 和一句「No recent rollout events」，右边 55% 装不下比例反过来（1.35 : 1），因为左栏是表格、右栏是 KV。空区块不占位：RECENT ROLLOUT EVENTS 没有内容时不渲染标题，塌缩成 rollout history 底部的一行灰字。
Pods / Rollout history 被渲染成整行文本块：Pod · agentconnect / mcp-kubernetes-59dc944695-8hknl 占满一行，右边还有个被切一半的 P；rollout history 的 ReplicaSet 列溢出用真表格：Pods 表给 name/ready/status/restarts/node/age，rollout history 给 rev/replicaset/tag/when，都设固定列宽 + 单元格省略。namespace 不再重复——详情头已经写了。
操作区 5 个按钮 + 4 个 Tab 挤一行：Copy name / Actions / Delete… / Restart… / Scale…，其中 Copy name 已经在快捷键里，Actions 又是个菜单只留高频的 Scale… Restart…，其余（Copy name、Copy YAML、Rollback、Pause rollout）收进 ⋯ Actions ▾，Delete… 单独放最右并保持红色。9 个控件降到 4 个。
IDENTITY 重复 Name / Namespace，而详情头第一行已经写了 Deployment · agentconnect / mcp-kubernetesIDENTITY 只留 Created / UID / Managed by。同一事实在一个面板里只出现一次。
列表列宽失衡：Namespace 和 Name 之间一大片空白，Created 右侧 350px 全空固定列宽 + Name 弹性：NAMESPACE 150 · NAME flex · READY 60 · STATUS 104 · IMAGE 230 · AGE 56。空出来的宽度给 IMAGE——这是排查时真正想看的列，也让「哪些服务还在跑旧版本」一眼可见。
Created 列全是 20 字符时间戳，占宽且不可比默认显示相对时间（47d，右对齐等宽数字），hover 出完整时间戳，表头旁一键切绝对时间。
状态没有颜色和形状，16 行 1/1 ready 长得一模一样，扫不出异常● Available / ▲ Progressing / ✕ Failed，形状与颜色同时携带信息；ready 数不足时该数字本身也变黄。
每个单元格自带高亮块，宽度参差；选中只高亮 Name 一格并加 ▶取消 per-cell 背景，hover 高亮整行，选中高亮整行 + 左侧 3px 蓝条。▶ 标记去掉。
顶部两行只承载一点信息：Live · synced just now 独占一行；All namespaces ▾ Namespace 把标签放在控件后面合成一行：搜索框 + Namespace: all ▾ + Status: all ▾ + 列开关 + 右端 live 指示。标签写进控件内部。下面补一条 10px 的匹配数/排序说明行，比原来的空行有用。

三条通用规则

写进规范就不会再出现同类问题
规则说明
长值中间省略，绝不裁尾镜像、selector、UID、URL 的区分信息都在尾部。统一实现一个 truncate_middle(text, avail_px)，配 tooltip 与复制按钮。
单行控件区不换行、不裁切宽度不足时把尾部元素收进 ⋯ 溢出菜单，而不是让它被窗口边缘切掉。生命体征带、工具栏、操作区都适用。
空区块不占位没有数据的 section 不渲染标题，塌缩为相邻区块底部的一行灰字，或整块隐藏。当前「RECENT ROLLOUT EVENTS / No recent rollout events」两行换来零信息。

实现侧：列表用 TableBuilder 的 Column::exact / Column::remainder 配 clip(true)；行选中用 Response::clicked + 整行 painter.rect_filled，不要 per-cell SelectableLabel；chip 带 on_hover_text；溢出菜单用 ui.menu_button("⋯", …)；空选中时详情区高度设 0 并保留 Separator 作拖拽把手。
