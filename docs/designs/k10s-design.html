§0

视觉语法

先定规则，再画界面
整套 UI 只有一条核心区分：有边框有填充 = 可以按，没有 = 只读数据。之前的状态 chip 违反了它，看起来像一排按钮却毫无 hover 反馈。
形态含义用在哪
边框 + 填充 + 3px 圆角可点击，有 hover 反馈按钮、下拉、输入框、Tab、labels chip
无边框 + 无填充只读数据，鼠标划过零反应状态栏、KV 值、表格单元格
全圆角 pill + 纯色底 + 无边框分类标记，一屏最多一个状态栏首位的主状态
虚线边框可展开的省略+3 ▾、溢出 ⋯
比容器更深的底 + 上下细线嵌入的读数区底部状态栏、日志/YAML 视图
文字末尾 …点击后还会再问一次（弹框/需输入）Delete… Scale… Restart…；Pop out 这类立即生效的不带

自检：如果一个元素 hover 不变亮，它就不该看起来是凸起的。

状态编码

形状与颜色同时携带信息，不依赖单一通道
● 正常 Running / Available / Ready
▲ 需关注 Pending / Progressing / Degraded
✕ 失败 CrashLoop / Failed / Forbidden
○ 无 / 未知 No selection / Unknown
链接与跳转 owner chain / more

三条排版铁律

长值中间省略，绝不裁尾镜像、selector、UID、URL 的区分信息都在尾部。ghcr.io/containers/…/kubernetes-mcp:v0.3.1，配 tooltip 与复制按钮。
单行控件区不换行不裁切宽度不足时从右往左收进 ⋯，而不是被窗口边缘切掉。状态栏、工具栏、操作区都适用。
空区块不占位没有数据的 section 不渲染标题，塌缩为相邻区块底部一行灰字，或整块隐藏。

§7

YAML 编辑守卫

只读 → 编辑 → 审查 diff → dry-run → 应用

决策清单

1–16 沿用原 README，17–32 为本轮新增
#决策
1–16沿用原 README：egui 默认视觉语言、内窗工作区、只开 Overview、左侧固定启动器、高亮代替勾选框、Workloads 可折叠分组、允许多开列表窗口、Custom Resources 有界、默认集成详情、保留显式弹出、按 owner 解析 Deployment 的 Pods、操作工具放在详情 Tab、YAML 变更守卫、Shell 显式连接、每个变更可见作用域、context 全局 / namespace 局部。
17键盘是一等入口。命令面板同时承担资源跳转、开窗与命令；列表内行游标与选中分离；所有鼠标动作都有等价快捷键。
18窗口寻址靠底部任务栏，按「类型 · namespace」区分同类多实例；侧栏徽标只表示数量。
19提供 Tile / Cascade / Focus 布局命令，并按 context 保存恢复窗口布局。
20侧栏覆盖排障闭环所需的全部分类：Cluster、Workloads、Network、Config、Storage、Access；分组可折叠，顶部有过滤框。
21焦点用标题栏强调色表示，不用透明度压暗未聚焦窗口。数据可读性优先于层次感。
22详情面板自带弹出与最大化；切到 Logs 或 Shell 时若高度不足则自动最大化。
23日志支持 --previous、since、按容器切换、换行、查找、导出；CrashLoopBackOff 时默认展示上一次终止的容器。
24列表虚拟滚动，始终显示「匹配 N / 共 M」与当前排序；筛选尽可能下推为 field selector。
25破坏性操作走统一确认面：作用域表 + 影响预估 + server dry-run + 键入名称 + 等效 kubectl 命令。
26每个窗口独立表达新鲜度与失败；数据陈旧时禁用变更操作；403 说明缺哪个 verb/resource；空列表区分「无资源」与「被筛掉」。
27状态不只靠颜色：● 正常、▲ 需关注、✕ 失败、○ 无。UI 缩放在 View 菜单可调。
28切换 context 前检查未保存 YAML 缓冲与活动 shell 会话，逐条列出后再让用户决定。
29视觉语法唯一化：有边框有填充 = 可点击；只读数据无边框无填充；全圆角 pill 是分类标记且一屏最多一个；按钮文字末尾的 … 专指「还会再确认一次」。
30每个窗口一条底部状态栏，位置固定高度 27px：有选中时描述选中项，无选中时描述列表本身。右端固定 live 指示与 ? keys。取代了原来的快捷键常驻行。
31Service 以 endpoint 健康为核心：列表把 ENDPOINTS 作为一等列；详情自动判定「零 endpoint」的成因——selector 未匹配 / Pod 未 ready / targetPort 不存在——并给出下一步入口，而不是列一张空表。
32Port-forward 与 Shell 同规格：显式 Start 才建立会话，活动会话进任务栏，切换 context 前列入待处理清单。

egui 实现要点

部件做法
列表表格TableBuilder + Column::exact / remainder 配 clip(true)；行选中用整行 painter.rect_filled，不要 per-cell SelectableLabel（那会产生宽度参差的高亮块）
状态栏TopBottomPanel::bottom(id).exact_height(27.0)，底色 from_gray(16)；外层 ui.horizontal() 默认居中，pill 的 inner_margin 上下必须相等，否则会偏
pillFrame::none().fill(tint).rounding(11.0) 包一个 Label，不加 stroke、不加 Sense::click
只读数据项裸 Label 对，间距 ui.add_space(20.0)；全程不拿 Sense::click()，鼠标划过零反馈
长值省略统一实现 truncate_middle(text, avail_px)，配 on_hover_text 与复制按钮
溢出布局时算 ui.available_width()，不够就停止 push 并显示 ui.menu_button("⋯", …)
两栏详情ui.columns(2, …)，available_width() < 760.0 时退化为单栏并折叠元数据区
折叠区CollapsingHeader；labels 用 ui.horizontal_wrapped 里的圆角 Frame（这些是可点的，需补 hover 高亮）
命令面板Area + Order::Foreground，输入用 TextEdit::singleline 配 request_focus()；结果列表用 SelectableLabel
空选中详情区高度设 0 并保留 Separator 作拖拽把手，列表自动吃掉这块高度
