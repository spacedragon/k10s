B · Integrated split detail Recommended

Selection drives a resizable detail pane inside the same resource window. The list can collapse when Logs, Shell, or YAML needs more space.

Pros

  • Stable, predictable window count
  • Faster list-to-detail navigation

Cons

  • One detail visible per list window
  • Requires resizing for dense tools
